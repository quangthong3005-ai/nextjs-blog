---
title: 'What Is an Audio Plugin?'
date: '2026-10-01'
---

An audio plugin is a small piece of software that runs **inside** a digital audio workstation (DAW) and processes or creates sound. Instead of building a whole music program, a plugin does one job well: a compressor controls dynamics, an EQ shapes tone, a synth makes new sounds.

## Two main kinds

- **Effects** take audio in, change it, and send it out. Compressor, EQ, noise gate, saturation, chorus and distortion are all effects.
- **Instruments** generate audio, usually when they receive MIDI notes.

## Plugin formats

The same idea is packaged in different formats, and each DAW supports a different set:

- **AU (Audio Units)** is Apple's format. Logic Pro loads Audio Units.
- **VST3** is widely used on Windows and macOS in many DAWs.
- **AAX** is used by Pro Tools.
- **CLAP** is a newer open format.

If you build plugins for Logic Pro, the format you need is **AU**.

## Why build your own?

Building a plugin teaches you real-time programming and digital signal processing at the same time. You write code, then you *hear* the result right away, which makes it a great way to learn.
